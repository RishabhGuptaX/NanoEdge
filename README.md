NanoEdge 🫁

AI-Powered Respiratory Health Risk Assessment

NanoEdge is an AI-powered respiratory health assessment application designed to provide an early risk assessment using patient health and physiological parameters.

🌐 Live Demo: https://nanoedge-frontend.onrender.com

📂 GitHub: https://github.com/RishabhGuptaX/NanoEdge

---

🚀 Overview

NanoEdge combines a machine learning model with a web-based interface to analyze patient information and provide an AI-driven respiratory health risk assessment.

The application takes relevant demographic, medical, and physiological parameters as input and processes them through a trained machine learning model.

«Disclaimer: NanoEdge is an educational/research project and is not intended to replace professional medical diagnosis or treatment.»

---

✨ Features

- 🧠 Machine-learning-based health risk prediction
- 🫁 Respiratory health assessment
- 📊 Analysis of patient health parameters
- 🌐 Interactive web interface
- ⚡ Fast prediction through an API-based backend
- ☁️ Deployed online using Render
- 📱 Accessible through a web browser

---

🧾 Input Parameters

The application can use patient information such as:

- Age
- Sex
- Diabetes
- Hypertension
- Obesity
- Asthma
- Tobacco usage
- Body temperature
- Oxygen saturation (SpO₂)
- Heart rate
- Respiratory/gas-related measurements

💻 Running Locally

1. Clone the repository

git clone https://github.com/RishabhGuptaX/NanoEdge.git
cd NanoEdge

2. Create a virtual environment

python -m venv venv

Activate it:

Windows

venv\Scripts\activate

Linux/macOS

source venv/bin/activate

3. Install dependencies

pip install -r requirements.txt

4. Start the backend

uvicorn api:app --reload

The API will be available locally through the Uvicorn server.
